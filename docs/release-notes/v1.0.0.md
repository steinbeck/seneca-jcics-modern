# SENECA 1.0.0 for macOS

SENECA proposes structures for an unknown organic compound from its molecular formula and its NMR spectra.
This is the first release of a port of the 2001 program (Steinbeck, *J. Chem. Inf. Comput. Sci.* 2001, 41,
1500–1507, [doi:10.1021/ci000407n](https://doi.org/10.1021/ci000407n)) to Java 25 and CDK 2.13, as a Mac app
with its own Java runtime.

- The algorithm, the seven judges and the windows are those of 2001. With the same seed, a run takes the same
  path as in the original program; this is checked against a golden master recorded with the 2001 code.
- Distributed computing over Java RMI is gone: runs execute in threads inside the app, several at once.
- Crashes, hangs and data loss of the 2001 program are fixed, for example the ring-finder crash of the Features
  judge. Every difference from 2001 is listed in
  [docs/port/DEVIATIONS.md](https://github.com/steinbeck/seneca-jcics-modern/blob/main/docs/port/DEVIATIONS.md).
- The ten example datasets of 2001 are built in (**File > Open > Example Dataset**).

**Getting started:** the README walks through a complete run of polycarpol, with screenshots:
[Quick start: run polycarpol step by step](https://github.com/steinbeck/seneca-jcics-modern#quick-start-run-polycarpol-step-by-step).
A German user guide is in
[docs/USER-GUIDE.md](https://github.com/steinbeck/seneca-jcics-modern/blob/main/docs/USER-GUIDE.md).

## Requirements

- A Mac with Apple silicon (M1 or later). Intel Macs are not supported by this download.
- macOS 11 (Big Sur) or later as declared by the app; tested on macOS 26 (Tahoe).
- Nothing else: the app contains its Java runtime (Eclipse Temurin 25).

## Install

1. Download `Seneca-1.0.0-macOS-arm64.dmg` below.
2. Optional: check it. Download `Seneca-1.0.0-macOS-arm64.dmg.sha256` into the same folder, then:

   ```bash
   cd ~/Downloads
   shasum -a 256 -c Seneca-1.0.0-macOS-arm64.dmg.sha256
   ```

   The output should be `Seneca-1.0.0-macOS-arm64.dmg: OK`. SHA-256 of the image:
   `e15b856992f0b0b014b747e59d34292def8204aaab7fd07fffa8bd1323bfa549`
3. Open the image and drag **Seneca** onto **Applications**.

The image also contains `README.txt` (these instructions), `LICENSE.txt` and `THIRD-PARTY-NOTICES.md`.

## First start

The app is signed ad hoc, not with an Apple Developer ID, and is not notarized by Apple, so macOS blocks the
first start of a downloaded copy. You allow it once.

**macOS 15 (Sequoia) and later:**

1. Double-click Seneca in Applications. macOS says *“Seneca” Not Opened*. Click **Done**, not Move to Trash.
2. Open **System Settings > Privacy & Security** and scroll down to the **Security** section. Next to
   *“Seneca” was blocked to protect your Mac.* click **Open Anyway**.
3. In the dialog *Open “Seneca”?* click **Open Anyway** and confirm with your password or Touch ID.

**macOS 14 and earlier** (not tested): Control-click Seneca in Applications, choose **Open**, then click
**Open**.

**Any version, in Terminal:**

```bash
xattr -drs com.apple.quarantine /Applications/Seneca.app
```

## Good to know

- Several constitutions often reach the maximum score. The run's "Best structure" is the last of them that
  was found; use **Summarize Result** to see all of them. The quick start shows this for polycarpol.
- As in 2001, the judge configuration is not saved in `.sml` files: after opening a file, press
  **Autoconfigure Judge** again.
- As in 2001, the judges Hybridization and Heterobond Attachments score 0, and Hybridization makes the
  maximum score unreachable. Leave both inactive.
- SENECA works on constitutions; stereochemistry is not considered.
- The app writes `seneca.log`, `seneca.results.sdf` and `seneca.annealing.log` into the home folder and empties
  them at every start (`--logdir=<folder>` puts them elsewhere).
